# ARTKRILIK ERP V3.3 — PHASE 15
## SECURITY & AUTHORIZATION PROMPT

Audit and implement security.

Review:

- authentication
- authorization
- roles
- permissions
- action visibility
- API authorization
- backend validation
- input validation
- injection protection
- CSRF where applicable
- secret management
- audit logging
- sensitive data exposure
- client-side trust boundaries

IMPORTANT:

Frontend visibility is not authorization.

Every protected action must be enforced server-side.

Define:

ROLE
→ PERMISSION
→ RESOURCE
→ ACTION

Validate:

Production
Admin
Finance
Sales
Warehouse
Management

Do not invent roles without approval.

Produce Security Audit Report before changes.
