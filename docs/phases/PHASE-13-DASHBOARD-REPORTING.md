# ARTKRILIK ERP V3.3 — PHASE 13
## DASHBOARD & REPORTING PROMPT

Design and implement Dashboard only from validated ERP data.

Do not invent business metrics.

Every KPI must have:

Metric Definition
Source
Calculation
Filter
Time Range
Permission
Refresh Strategy

Potential domains:

Sales
Payment
Production
Packing
Fulfillment

Do not duplicate domain calculations inside dashboard.

Dashboard consumes domain/application queries.

Validate every KPI against underlying transaction records.

Do not use legacy KPI implementation as authority.
